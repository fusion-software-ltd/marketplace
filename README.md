**Decision tools for people who think before they act.**

This is the official plugin marketplace for [Fusion Software](https://fusionsoftware.com). Install plugins directly into Claude Cowork or Claude Code.

## Available Plugins

### 🏛️ Decision Council
**AI advisory panel for decisions that matter.**

Assembles a panel of independent AI advisors to debate your decision from multiple angles, cross-examine each other's reasoning, and deliver a scored recommendation with a visual dashboard.

**What you get (free):**
- 5 advisors + Chair orchestrator — Optimist, Pessimist, Devil's Advocate, Pragmatist, Behaviourist
- Cross-examination when advisors disagree by 30+ points
- Consensus danger check (catches groupthink)
- Behaviourist process audit (catches your biases)
- One-line summary + full synthesis + next actions
- Visual HTML decision dashboard
- Post-session debrief: pre-mortem, Mirror (brutal truth), crux questions
- Decision recording and feedback loop
- Cross-session memory in Cowork projects

**Commands:**
- `/decision-council:convene [question]` — full council session
- `/decision-council:debrief` — challenge, decide, and give feedback
- `/decision-council:quick [question]` — 3-advisor fast mode
- `/decision-council:configure` — adjust your panel
- `/decision-council:pro` — browse upcoming Pro features

**Works on:** Claude Cowork · Claude Code

→ [Plugin repo](https://github.com/fusion-software-ltd/decision-council)

---

## How to Install

1. In Claude Cowork, go to **Settings → Plugins → Add marketplace**
2. Enter: `https://github.com/fusion-software-ltd/marketplace`
3. Click **Sync**
4. Install **Decision Council** from the marketplace list
5. Run `/decision-council:convene Should I [your decision]?`
